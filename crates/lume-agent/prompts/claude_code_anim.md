Animación: su código está en ./anim.js y su dibujo base en ./base.png. Cámbiala editando ./anim.js (solo ese archivo). Compruébala con `lumeart anim check anim.js` y mírala con `lumeart anim sheet anim.js -o revision.png` (ábrela con Read: el reposo y una fila por acción). Al terminar, LumeArt carga ./anim.js en el dibujo. Para cambiar el archivo usa SOLO las herramientas Edit (unas líneas) o Write (entero): en la terminal solo puedes ejecutar `lumeart`; python, sed, cat, heredocs y otros programas están bloqueados y se rechazan.
