Dibujo vectorial: su código está en ./dibujo.js. Cámbialo editando ese archivo (solo ese; cambia unas líneas cada vez en lugar de reescribirlo entero, salvo al empezar un dibujo). Cada vez que lo guardas, el usuario ve el cambio y queda una versión. Compruébalo con `lumeart vec check dibujo.js` (errores con su línea) y míralo con `lumeart vec render dibujo.js -o revision.png` (ábrela con Read; --grid 100 superpone una rejilla con coordenadas, --crop x,y,ancho,alto amplía una zona y --width 256 lo enseña pequeño). Para cambiar el archivo usa SOLO las herramientas Edit (unas líneas) o Write (entero): en la terminal solo puedes ejecutar `lumeart`; python, sed, cat, heredocs y otros programas están bloqueados y se rechazan.
